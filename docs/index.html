Multilingual corporate website with TYPO3

A website in English, German and French for Fluvenco, a fictional manufacturer of hydraulic components. Besides the site itself, the project covers the work around it: an editor guide, a translation process for country websites, SEO and automated quality checks.

The website

Home, products, industries, service, news, company, careers and contact, with a language switcher (EN, DE, FR) and a responsive layout without tracking or external scripts.

What was built

Typical tasks of a website team and how the project covers them.

TaskIn this project
Maintain international websites in TYPO3Own sitepackage: Fluid templates, TypoScript, site sets, backend layout and two custom content elements
Launch country websites and coordinate translationsConnected translations, localized URLs (/en/, /de-de/, /fr-fr/), documented translation and approval process with glossary and go-live checklist
Train and support editorsEditor guide, user groups per role (central team, German and French translators) with restricted languages and content elements
Quality assurance and testingAutomated check of all pages with Playwright and axe-core, QA checklist and report
Web design and SEOResponsive design, titles and descriptions per language, canonical, hreflang, XML sitemap, alt texts

The online version is a static export of the TYPO3 installation, so it runs without a server. The full TYPO3 instance can be rebuilt locally with composer install and Build/reset.sh. Editor documentation is in German, as for a German team.
